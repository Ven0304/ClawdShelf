# Notice

ClawdShelf is an unofficial fan project.

## Clawd

The Clawd character belongs to [Anthropic](https://www.anthropic.com). This project is not affiliated with or endorsed by Anthropic, and its license grants no rights in the character.

The pixel art in `src/ClawdArt.cs` is drawn in code for this project, following the shape of the Claude Code mascot. The hats, expressions and props are original to this project. No artwork from other projects is included.

## Inspiration

- Tendedero (macOS) and oldplusnew/Clothesline (Windows), for the idea of hanging screenshots on a line. No code from either is used.
- [clawd-stickers](https://github.com/alwinecor/clawd-stickers), for the flat, outline-free look and the idea of giving Clawd a hat. No images or code from it are used.
